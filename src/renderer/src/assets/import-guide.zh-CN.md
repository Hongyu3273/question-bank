# 题库导入格式说明

支持三种文件,可以一次选择多个:

| 格式 | 适合 | 图片 |
|---|---|---|
| `.zip` 压缩包 | 带图片的题库(推荐) | 支持 |
| `.md` Markdown | 纯文字题库 | 不支持 |
| `.xlsx` Excel | 表格整理的题目 | 不支持 |

## 一、Markdown(.md)

```markdown
# Java 基础

## HashMap 和 Hashtable 有什么区别?
---answer---
1. HashMap 线程不安全,Hashtable 线程安全
2. HashMap 允许 null 键和 null 值

## 什么是 JVM?
---answer---
Java 虚拟机,负责运行字节码。

![JVM 结构](images/jvm.png)
```

规则:

- 第一行 `# 标题` 是题库名;不写时用文件名
- 每个 `## ` 开始一道题,后面的文字就是题干(不超过 500 字)
- 题干下一行单独写 `---answer---`,之后直到下一个 `## ` 都是答案
- 题干和 `---answer---` 之间不要写其他内容
- 答案支持 Markdown:列表、表格、代码块、公式、图片;答案里的小标题用 `###`
- 代码块里的 `##` 和 `---answer---` 不会被当作分隔

## 二、题目信息(可选)

写在答案的最开头:

```markdown
## 介绍一下你自己
---answer---
*English: Tell me about yourself.*

> 优先级：高 ｜ 分类：通用 ｜ 出处：SEEK

答案正文……
```

- `*English: …*`:英文题干,可在设置中开关显示
- 优先级填 `高`、`中`、`低`;各项之间用 `｜` 或 `|` 分隔,每项都可省略
- 没有优先级的题目归入"未设置",导入后可在题库管理中批量设置

## 三、压缩包(.zip,带图片)

```text
Java 基础.zip
└── Java 基础/
    ├── questions.md
    └── images/
        └── jvm.png
```

- 每个文件夹放一个 `questions.md` 和一个 `images/` 图片文件夹
- 答案中用 `![](images/jvm.png)` 引用图片
- 一个压缩包里可以放多个题库文件夹,会一起导入
- 图片支持 png、jpg、gif、webp、svg,单张不超过 10 MB

## 四、Excel(.xlsx)

读取第一个工作表,第一行是表头,之后每行一道题:

| 题干 | 答案 | 优先级 | 分类 | 英文题干 | 出处 |
|---|---|---|---|---|---|
| 什么是 JVM? | Java 虚拟机,负责运行字节码。 | 高 | Java | What is the JVM? | 面经 |

- 必需列:`题干`(也可写 题目、问题、question)和 `答案`(也可写 参考答案、answer)
- 其余列可选,列的顺序不限
- 题库名使用文件名;不支持图片

## 五、导入时

- 已有同名题库时会询问:覆盖、另存为新题库或跳过
- 格式有问题时会列出具体的题号和行号,其余题目照常导入
- 可以在"设置 → 数据"中下载 Markdown 和 Excel 模板

> 提示:可以把这段说明连同你的资料一起发给 AI,让它按这个格式整理成题库文件。
