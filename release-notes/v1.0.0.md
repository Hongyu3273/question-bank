知识题库的第一个正式版本:离线使用,不需要账号,数据只保存在你自己的电脑上。

## 下载哪个文件

| 系统 | 文件 |
|---|---|
| Windows 10 / 11 | `question-bank-1.0.0-win-x64.exe` |
| Mac(Apple 芯片:M1 / M2 / M3 / M4) | `question-bank-1.0.0-mac-arm64.dmg` |
| Mac(Intel 芯片) | `question-bank-1.0.0-mac-x64.dmg` |

不确定 Mac 是哪种芯片:点左上角  → 关于本机,看"芯片"或"处理器"一栏。

`.zip`、`.yml`、`.blockmap` 文件是自动更新用的,不需要下载。

## 第一次打开

软件没有购买代码签名证书,所以系统会提示来源未知,这是正常的。

- **Windows**:如果出现"Windows 已保护你的电脑",点"更多信息"→"仍要运行"。
- **Mac**:把"知识题库"拖进"应用程序"文件夹后,第一次打开如果提示"无法验证开发者",到"系统设置 → 隐私与安全性",在页面下方点"仍要打开"。
  如果提示"已损坏,无法打开",在终端运行下面这行再打开:
  ```
  xattr -cr /Applications/知识题库.app
  ```

## 主要功能

- **看题模式**:按顺序看所选题库的全部题目,带目录、搜索、优先级筛选;双击题目放大查看;可以"遮住答案"自测;Ctrl + 滚轮缩放内容。
- **背题模式 · 今日任务**:用 FSRS 记忆曲线安排复习。看完答案自评"不会 / 模糊 / 记住",不会的 10 分钟后再出现,记住的间隔越来越长;每个题库可设置每日新题数和复习上限。
- **背题模式 · 全部刷一遍**:所选题库洗牌后逐题过一遍,适合考前冲刺。
- **错题本**:答"不会"的题自动加入,在不同的两天都答"记住"后自动移出,也可以手动移出。
- **学习概况**:连续学习天数、最近 7 天的自评、未来 7 天到期的题、各题库的掌握情况。
- **题库管理**:软件内编辑题目(Markdown + 图片),导入导出 zip / Markdown / Excel,拖动排序,批量设置优先级;看题、背题时也可以按 E 直接修改当前题目。
- **数据安全**:每天第一次打开时自动备份,保留最近 7 份;也可以手动导出完整备份,在其他电脑上恢复。
- **其他**:浅色 / 深色主题,中文 / 英文界面,大窗口自动放大字号。

## 更新

软件打开后会自动检查新版本,也可以在"设置 → 关于 → 检查更新"手动检查。Windows 会在后台下载,完成后提示重启安装;Mac 会提示前往下载页面。更新不会影响已有的题库和学习记录。

**English summary** — The first release of Question Bank, an offline desktop app for reviewing interview questions. Download the `.exe` for Windows or the `.dmg` for your Mac's chip (arm64 for Apple silicon, x64 for Intel). The app isn't code-signed: on Windows choose *More info → Run anyway*; on macOS allow it under *System Settings → Privacy & Security*, or run `xattr -cr /Applications/知识题库.app` if macOS says the app is damaged. Features include Read mode, spaced-repetition Recite mode (FSRS), a mistakes list, study stats, in-app editing, import/export and daily automatic backups.
