# 知识题库

[English](README.md) | **简体中文**

面向自己和少数人的复习工具,以简答题为主。桌面应用,支持 macOS 和 Windows,离线使用,不依赖服务器。

## 功能

- **看题模式**:连续展示所选题库的全部题目和答案;目录可折叠、可拖动调整宽度;全文搜索(Ctrl+F);点击题干放大单题,← → 切换;记住阅读位置。
- **背题模式**:所选题库合并后随机洗牌,每次一题、答案默认隐藏;点击答案区域或按空格显示;一轮内每题出现一次,结束后自动重新洗牌;关闭软件后进度保留。
- **优先级筛选**:答案开头的"优先级 / 分类 / 出处"显示为标签,可以只看、只背高优先级的题。
- **题库管理**:题库和题目的增删改、拖动排序;Markdown 编辑器(工具栏、预览、代码高亮、表格、公式、粘贴图片)。
- **导入导出**:Markdown 压缩包(含图片)、单个 .md、Excel .xlsx,可多选;格式问题精确到题号和行号;同名题库可覆盖、另存或跳过。
- **备份恢复**:题库、图片、进度和设置打包为一个 .qbak 文件。
- **设置**:浅色 / 深色 / 跟随系统、三档字号、中文 / English 界面、显示或隐藏英文题干。
- 考试模式:暂未开放。

## 使用流程

1. **导入题目**:打开"题库管理"→"导入题库",选择一个或多个 .zip / .md / .xlsx 文件;也可以"新建题库"手动录入。模板在"设置 → 数据"中下载。
2. **选择范围**:在首页"① 选择题库"中勾选题库,需要时选择优先级(例如只看"高")。
3. **选择模式**:
   - **看题模式**:从头到尾阅读题目和答案。点题干或放大按钮进入单题视图,← → 切换,Esc 关闭。
   - **背题模式**:先自己回想,再点击虚线区域(或按空格)看答案,→ 下一题。
4. **随时修改**:在"题库管理"中编辑题目,修改立即生效。任意页面按 ? 查看全部快捷键。
5. **备份数据**:"设置 → 数据 → 导出备份"生成 .qbak 文件,可在其他电脑上恢复。

技术栈:Electron · TypeScript · React · Vite(electron-vite)· SQLite(sql.js,WebAssembly 版,无需本机编译)

## 开发环境

需要安装:

- [Node.js](https://nodejs.org/) 22.12 或更高版本
- [Git](https://git-scm.com/)

```bash
npm install     # 安装依赖
npm run dev     # 启动开发模式(改代码后界面自动刷新)
```

其他命令:

| 命令 | 作用 |
|---|---|
| `npm test` | 运行单元测试 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run build` | 编译到 `out/` |
| `npm run dist:win` | 打包 Windows 安装包到 `dist/` |
| `npm run dist:mac` | 打包 macOS 安装包到 `dist/`(需要在 Mac 上执行) |

Windows 上如果 PowerShell 提示"禁止运行脚本",先运行一次:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 题库文件格式

导入支持三种文件,可以一次选择多个:

- **Markdown 压缩包(.zip,推荐)**:`<题库名>/questions.md` 加同级的 `images/` 图片文件夹。一个压缩包里可以有多个题库。
- **单个 Markdown 文件(.md)**:不带图片。
- **Excel(.xlsx)**:第一个工作表,第一行表头需要"题干""答案"两列。

`questions.md` 的写法:

````markdown
# 题库名

## 第一道题的题干

---answer---

答案,支持 **Markdown**、代码块、表格、公式 $O(n)$ 和图片 ![](images/a.png)

## 第二道题的题干

---answer---

……
````

导出的题库使用同样的格式。设置页可以下载 Markdown 和 Excel 模板。

## 目录结构

```
src/
├─ shared/      主进程与界面共用的类型和 IPC 接口定义
├─ main/        主进程:窗口、数据库、文件读写
│   ├─ db/      连接、迁移、各表的读写
│   └─ ipc/     界面可调用的接口
├─ preload/     把白名单接口暴露为 window.api
└─ renderer/    React 界面
    └─ src/
        ├─ components/  侧边栏、提示等通用组件
        ├─ pages/       首页、看题、背题、题库管理、设置
        ├─ stores/      Zustand 状态
        ├─ i18n/        中文和英文文案
        └─ styles/      设计 token(浅色/深色)和全局样式
```

用户数据保存在系统的应用数据目录(`app.db` 是数据库,`assets/<题库 id>/images/` 是题目中的图片):

- Windows:`%APPDATA%\知识题库\`
- macOS:`~/Library/Application Support/知识题库/`
